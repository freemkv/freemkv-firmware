A release-negative certificate must bind:

1. The exact installed/incoming context or an explicit finite membership predicate.
2. The required input and why the selected direction/construction actually requires it.
3. The held-source boundary demonstrating its absence or unbound mandatory identity.
4. Any available conditional context, accepted no-op or alternative complete proof path excluded from that predicate.
5. The remainder: supported, separately release-negative, or still internally unresolved.

Unfinished design, an unsuccessful strategy, an unproved internal invariant, elapsed time, or a missing detector is not a missing external input. Those cases remain open.
