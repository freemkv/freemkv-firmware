# 0.14.2 release evidence

Pioneer hardware-family matching now uses pioneer-optical 1.0.1 and the
`pioneer.hardware.v2` scheme. The optical library always includes the servo
coefficient fingerprint, including boards with `ffc5=20` that formerly omitted
it. A missing signature is the explicit `none` fingerprint, not evidence that
servo hardware is absent.

The locally held hoard contains 521 recognized package fingerprints. Recomputed
production identifiers match the reviewed report for all 521. Families split
from 22 to 25, separating 134 previously matching model/SAT/destination variant
pairs. These counts describe the held corpus, not physical crossflash tests.

The Flash planner continues to use the optical library's family identity for
both target selection and installed receiver checks. A synthetic regression
keeps identical register configuration while adding a servo table and verifies
that the resulting family difference reaches the refusal gate. Published-crate
pin regressions separately require Pioneer 1.0.1 and MediaTek 1.0.0, including
registry checksums; no local path override is shipped.

Release follows dev to qa to main, with the existing native tests, cross-platform
lint, debug/release tests and package smoke checks. No physical drive write is
performed by these checks. Family equality compares extracted firmware evidence;
it does not certify every physical cross-model combination.
