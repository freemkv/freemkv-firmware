# App error-message audit (item 1)

This is a source-level inventory of **presentation routes**, not a claim that
every possible backend error string or hardware response was exercised. It
covers the freemkv-flash CLI, flash GUI, firmware-authoring GUI, shared
workflow/error classification, and the embedded UI catalogs. Diagnostic logs
are intentionally English; status, failure, and guidance widgets use message
IDs. Protocol policy, PREPARE behavior, and optical dependencies are outside
this item.

## Error presentation routes

| Route | User-facing sink | Technical evidence | Reviewed outcome |
|---|---|---|---|
| CLI argument parsing (`freemkv-flash/src/main.rs`) | clap stderr/help | No operation log exists yet | English CLI validation remains clap-owned. |
| CLI workflow failure (`main.rs`, `workflow.rs`, `user_error.rs`) | English catalog guidance on stderr | `diagnostics::run` records the error chain and update evidence | Typed update/inspection cases take precedence over text heuristics. |
| CLI completed-but-unverified update (`main.rs`) | Typed consequence guidance | Returned `UpdateOutcome` is retained in the error | No generic “try again” after an unverified target or possible temporary firmware. |
| Flash GUI operation (`ui.rs::run_job`, `App::poll`) | Localized status and failure | English events, typed `UpdateFailure`, phase and accepted-byte evidence | Blocked, entry attempted, payload uncertain, temporary image, and unknown outcome remain distinct. |
| Flash GUI analysis cancellation (`ui.rs::run_job`, `App::poll`) | Localized cancellation status; no failure card | English cancellation event | Cancellation is no longer displayed as a failed analysis with retry advice. |
| Flash GUI profile and origin workers (`ui.rs::start_profile`, `poll_profile`, `poll_origin`) | Localized unavailable/inspection guidance | English worker failure or disconnect detail | Origin disconnect now terminates “checking” and retains the selected file; stale results cannot relabel a new selection. |
| Flash GUI report and diagnostic export (`ui.rs::poll`, `chosen`, `diagnostic_text`) | Localized notices | English report/export error in the activity or diagnostic log | Report-worker disconnect now states submission outcome unknown. |
| Firmware GUI operations (`freemkv-fw-gui/src/ops.rs`, `app.rs::start_job`, `pump`) | Localized failure and status | English error chain and worker-panic detail | Existing-image and generated-image integrity failures retain distinct catalog guidance. |
| Firmware GUI boot preview and log actions (`app.rs::boot_preview`, `save_diagnostic_log`) | Localized error/notice | English analysis and file-I/O detail | Preview-worker disconnect reports unknown outcome in the log. |
| Native flash GUI shells (`mac.rs`, `windows.rs`, `linux.rs`, `egui_shell.rs`) | Render `App::view()` messages | Activity log is English | No separate shell-specific error classification found; Windows timer notice uses a catalog ID. |
| Shared localization (`freemkv-flash/src/localization.rs`, `locales/*.json`) | 29 embedded catalogs | `english()` resolves IDs for diagnostics | Catalog parity tests cover IDs; this audit did not perform native-speaker review. |

## Message-evidence rule

PREPARE is a zero-length WRITE BUFFER command. An attempted entry command can
change mode while sending **zero firmware payload bytes**. A failed payload
command establishes an attempt, not acceptance or programming. The UI must not
infer either claim from the legacy `write_started` flag. A zero sense triple
also does not establish whether a valid sense response was returned.

## Remaining limits

- `UserError::of` still uses English substring matching for untyped legacy
  errors. It can only give conservative guidance; more typed producer errors
  would improve precision, but this item does not change backend policy.
- Some firmware-authoring refusal reasons from `freemkv-fw` remain untyped and
  therefore receive generic shared guidance. Their full English chains stay
  in diagnostics. The unsupported inspection-format message currently uses
  the localized but terse “Not supported” key; its format name remains in the
  English log.
- Toolkit-generated file-dialog/OS errors and clap parse errors are not
  translated. Windows/Linux native shells were source-inspected but not run on
  this macOS host; physical-drive behavior was not exercised.
- All 29 catalogs have matching keys, but translations have not had
  native-speaker review. Raw sense length/validity requires a separate
  libfreemkv API change and is not fabricated here.
