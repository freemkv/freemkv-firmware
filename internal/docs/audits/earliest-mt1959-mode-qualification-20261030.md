# Earliest MT1959 reverse-mode qualification — 2026-10-30

Scope: BP50NB40 1.00 SHA-256 `c88a69013d557b9c4cf1a4d603c314585f51a258b9747c345184e866eef36306`. Read-only firmware analysis; no production changes, flashing, or hardware results. This is a bounded rejection of proposed bindings, not a whole-program proof that an equivalent state does not exist.

## Result

The existing 23-image mode contract cannot safely be bound to earliest B19 or to a simple interpretation of B01. Its positive contract requires a mode producer with the appropriate lifecycle and independently matching consumers, including the reverse calculation. The observed B01 producer is a speed/configuration negotiation path with multiple whole-byte assignments; it is not established to produce the reference phase. The minimum safe implementation is to continue to refuse G05 for this image, including both 12q and 9q routes, and thus refuse the all-or-nothing image conversion. A 12q default chosen merely because a mode source is absent would manufacture an unproven lifecycle and can conceal a required 9q path.

## Producer and consumers

Reproducing the bounded literal-pointer control-flow survey by changing its target from B19 to B01 gives `/tmp/freemkv-earliest-terra-b01.py` and `/tmp/freemkv-earliest-terra-b01.txt`. As with the original survey, seeds are in-image PC literals, paths are bounded, and indirect/interprocedural access can be missed; false-positive paths must be checked against disassembly. Selected checked instructions:

* `6BCBA..6BCCE` constructs B00 as R5 and, on the ordinary R1 != 2 path, `6BCCE` writes incoming R0 directly to B01. `6BD04..6BD0C` can clear B01 after speed/state checks. `6BE1C` sets it to 1 under a flag and a speed limit, and `6C05E..6C064` clears bits 2..4 while preserving other bits.
* `6C130..6C18A` uses media-derived conditions and writes speed at B0B as well as the whole value 2 to B01 at `6C150`, `6C15C`, `6C17A`, and `6C18A`. This is a concrete producer for packed selector value 1 (B01 bits 1..2), but it couples selection to speed/media configuration, not an identified reverse transition or coordinate threshold.
* At `7A84A..7A86E`, calibration reads media state, profile flag, and B01. Its first profile selection extracts B01 bits 1..2 and tests for 1; elsewhere the family uses a wider packed comparison. Existing `/tmp/freemkv-g05-earliest-calibration.py` exercises 36 combinations and shows three continuations for four packed configurations. This establishes B01 influences calibration; it does not establish equivalence to the older binary phase nor validate B01 as the reverse computation input. In particular whole-byte values 0 and 1 have the same extracted bits 1..2, while 2 selects 1, so using B01 nonzero as the reference phase would disagree with this consumer.
* Earliest B19 is separately used as a bitfield at `6F4F2` and `CB820..CBA98`; the calibration execution shows it does not select those profile continuations. It cannot be rebound just because the 23-image structure uses the same numeric address.

The producer evidence rules out the naive direct nonzero-B01 mapping and the address-only B19 mapping. It does not rule out a derived B01 predicate, another state byte, compiler-inlined transition, a computed writer, or resident code. In particular, interpreting B01 bits 1..2 == 1 as a candidate remains a hypothesis until its observed writer and both independent consumers are causally matched to reference phase entry and exit, including downstream coordinate compatibility. Configuration values 0, 2, and 3 have distinct producer/consumer implications and cannot be collapsed without such evidence.

## Missing contract and route to qualification

The concrete missing link is an image-derived C7 reverse operand that is proven to track the corresponding reference mode through entry, exit, reset, and normal read-command execution, plus evidence that its 12q/9q decisions match the existing earliest calibration and coordinate consumers. The earliest coordinate frame uses B00+34/+38; the later older layouts use +3C/+40. Any equivalence test must use the source-bound earliest offsets. The known reference operation's resident driver boundary also prevents treating a source-file direct-caller search as a reachability or lifecycle absence proof.

To advance safely, trace the B01 writer call chain and relevant resident driver mapping or obtain a real command trace; compare actual phase changes, calibration branch and coordinate output across zero/nonzero transitions against native behavior. An eventual helper must select `low16(R7 - 12 * floor(input/10))` for reference mode zero and `low16(R5 - 9 * floor(input/10))` for nonzero C7 mode, preserve all non-C7 and disabled paths, and use only storage/operands proven owned and valid for this image. Execute both routes and transition/reset paths on actual source bytes and integrate all other required image gaps before qualification. Arithmetic primitive equivalence alone does not supply the missing mode or show physical acquisition succeeds.

## Coefficient-load cross-check

`/tmp/freemkv-earliest-terra-table.py` executes actual selector instructions through the first coefficient loads for C7/C8, speed 2/4/8, earliest packed values 0..3 and both older binary values. Logging calls alone return directly; they supply no calibration results. The harness initializes writable RAM deterministically, sets source-bound state/speed/configuration explicitly, and preserves each image's source NV data. Results and actual memory addresses are in `/tmp/freemkv-earliest-terra-table.json`. These are isolated selector legs with manually seeded inputs, not actual lifecycle execution.

At C7, speed 4, earliest packed value 0/2 loads halfword `204` at `0x152950`, value 1 loads `256` at `0x152940`, and value 3 loads `204` at `0x152960`. The later older selector's second mode-sensitive leg loads `224` at `0x14DF1E` for mode 0 and `256` at `0x14DF3E` for mode 1. Its other selector leg loads `512` at `0x14DDD6` for mode 0 and `204` at `0x14DDA6` for mode 1. The shared 256 is positive local evidence consistent with packed value 1 and older mode 1 selecting related profiles; the other values and table addresses show these legs cannot be equated by value or base-offset alone. NV tables are image-specific, so differing coefficients are not themselves a semantic refutation. This experiment does not establish which old leg corresponds to earliest's context, or that either selector's state transitions match reverse mode. It does not justify installing the predicate `(B01 >> 1) & 3 == 1` as a reverse mode source.
