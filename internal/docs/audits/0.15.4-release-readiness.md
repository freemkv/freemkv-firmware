# 0.15.4 release preparation

Previous release: v0.15.3. Version remains 0.15.4. The customer changelog is in
CHANGELOG.md; this note records engineering scope and validation limits.

## Scope

- MT1939 UHD research is preserved at research/mt1939-uhd-detection, 7bcab5f,
  and pushed to origin. Remove the experimental conversion module and production
  Create/Modify wiring, plus its CI invocation. Regression checks native DI bytes
  remain unchanged and Unrestricted choices remain unavailable on classic input.
- Retain the DVD/BD Thumb-1 speed fix. Four native selector layouts pass 3840
  ARM926 comparisons. The generated install preserves the native LR and uses
  PUSH LR / BL rather than unsupported Thumb-2 B.W.
- Established MT1959 hooks and common integrity/allocation/boot fixes since
  v0.15.3 remain on dev. No new physical MT1959 trial is claimed for this release.
- Pin pioneer-optical 1.3.1 to d7ae773da92d37f05fa2740be98cdb6e0281e486.
  It enables only the retained owner-tested original UD02 mechanism to exact
  UD04 1.14 profile and pristine stock UD02 1.00 return. Firmware hashes, factory
  product and parameter 0x028f = 1 are required; other versions and native reverse
  conversions stay unsupported. Erased-tag factory records require full A0,
  structured product and factory-test/date evidence.
